# Test Case: UX de filtros y ordenamiento

## General Information

| Field              | Details    |
| ------------------ | ---------- |
| **ID**       | `UI-005` |
| **Module**   | UI         |
| **Priority** | Medium     |
| **Status**   | Passed     |

## Preconditions

- The application is available at https://fullstack.qa-practice.dev
- The user is on the Home page.

## Test Data

```text
Controls: Filters, Sort By, categories, price range, availability
States: active, inactive
```

## Steps

1. Open the Home page.
2. Review **Filters**, **Sort By**, categories, price range, and availability controls.
3. Identify visually which elements are interactive.
4. Review selected and unselected states for the controls.

## Expected Result

- It is clear which controls can be used.
- Active and inactive states are visually distinguishable.
- There is enough spacing between controls.
- Filters and sorting controls are easy to identify and use.
