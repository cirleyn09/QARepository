# API Testing - Postman

Práctica de pruebas de API REST utilizando Postman.

## Objetivo

Validar el comportamiento de una API mediante pruebas
funcionales, positivas, negativas y automatizadas.

## Herramientas

- Postman
- JavaScript
- REST API
- JSON

## Pruebas realizadas

- GET
- POST
- Status Code Validation
- Response Body Validation
- Authentication Testing
- Positive Testing
- Negative Testing

## Automatización

Los requests incluyen scripts de Postman para validar
automáticamente las respuestas de la API.
